# ChatDrop mark

The mark combines a chat bubble and an inbox tray in cobalt blue. The transparent
PNG is the master raster asset; `scripts/build-icon.sh` produces the macOS ICNS.
The iconset under `build/` contains 16–1024 pixel exports.

The initial mark was generated with `gpt-image-2.5-flare` in one call. The adjacent
JSON preserves the prompt and non-secret generation metadata. It is a raster logo,
not an SVG source.
